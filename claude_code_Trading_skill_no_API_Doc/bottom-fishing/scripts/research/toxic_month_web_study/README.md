# 毒月集中暴雷窗口 × 国内外事件研究

这是一个与 `bottom-fishing` 生产 workflow 隔离的研究目录。

研究问题：

1. 原始推荐线的毒月，坏信号和实际止损分别集中在哪 5 个真实交易日？
2. 这些窗口是否跨行业扩散，还是由少数股票/重复信号制造？
3. 集中窗口附近有哪些有时间戳的国内、国际事件？
4. 各事件与暴雷的关系属于直接冲击、风险放大、背景因素，还是仅仅同期发生？

口径：

- 原始推荐线不变：防守日总分 `>=18`，非防守日个股分 `>=15`，且 `ATR<=4`。
- 标签不变：`T+1` 开盘进场，20 个交易日内先到 `+5%` 为 win、先到 `-8%` 为 stop。
- 毒月不变：月信号数 `n>=15` 且 stop rate `>=30%`。
- 只使用已经完整走完标签窗的信号，当前成熟信号截止日为 `2026-06-15`。
- 当前固定面板得到 10 个严格毒月；`2024-07` 为 `29.9827%` 的阈值边界月，作为旧研究第 11 月单列，不冒充严格毒月。
- “集中 5 日”按连续 5 个真实交易日计算。旧脚本按 5 个“有信号的日期”滚动，可能跨越超过 5 个市场交易日。

文件：

- `analyze_toxic_windows.py`：只读固定研究数据，复算交易路径、集中窗口、指数表现及行业/个股集中度。
- `web_event_ledger.csv`：逐月的网页事件证据账本；URL 指向官方来源或 Reuters/AP 等有明确日期的报道。
- `EARLY_WARNING_DESIGN.md`：把事件拆成 T 日可知、正在演化和 T 日不可知三类，定义只进 shadow 的
  HTML warning 结构、证据纪律和无前视验证方案。
- 运行脚本后，派生结果写入 `C:\Trading_analysis\research\bottom_toxic_month_web_study\output`。

运行：

```powershell
python .\analyze_toxic_windows.py
```

本目录不修改 skill workflow、生产规则、权重、报告或影子日志。
