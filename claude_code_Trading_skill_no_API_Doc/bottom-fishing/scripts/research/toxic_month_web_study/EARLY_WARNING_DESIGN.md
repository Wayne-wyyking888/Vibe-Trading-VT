# 毒月 Web 事前预警研究设计

> 状态更新：本设计于 2026-07-23 最初以 Agent③ `bottom-toxic-risk-warning/v1` 接入日常 skill；

> 全市场发现、八行业族覆盖、重大异动归因、事件新鲜度/A股兑现审计、八类预测输入和分窗口A股映射，以
> `references/TOXIC_RISK_WARNING_PROTOCOL.md` 与 `references/AGENT3_SECTOR_MAPPING_PROTOCOL.md` 为准；
> 本文件只保留原始研究假设与升级前验证标准，不代表当前完整字段契约。

## 结论先行

Web search 可以在个股 HTML 中提供有价值的风险预警，但合理目标是“截至 T 日的风险 nowcast”，
不是准确预测下一个毒月。公开信息可以识别已经形成的压力、已排期事件和个股恶化证据；
尚未公开的战争、制裁名单、财务造假等突发事件不能被诚实地提前预知。

当前 HTML 已支持报告级 `alerts` 和候选股级 `alerts`。Agent③已由裁定层写入结构化 warning，并由独立
验收器检查 T 日截断、来源、候选映射和 HTML 可见性；不可变引擎、分数、结论、仓位与熔断仍未修改。

## 可预警性分层

### A. 预先排期、T 日已知

- 国家统计局宏观数据发布时间、PMI、LPR、FOMC 等公开日程；
- 春节、国庆等长时间休市和海外市场仍交易形成的信息累积窗口；
- 已公布且有生效日的退市/ST、关税、出口管制和行业监管规则；
- 个股已公告的年报/业绩预告、解禁、问询回复、诉讼和债务到期。

这类事件只能说明“波动或信息跳空概率上升”，不能预设利空方向。排期本身最多给黄色提示。

### B. T 日已经发生、仍在演化

- 已爆发且未解决的战争、航运阻断、油价冲击；
- 已确认的贸易限制、实体清单或行业政策冲击；
- 融资余额快速收缩、小微盘流动性踩踏、广谱跌停或异常交易监管；
- 个股基本面恶化、审计/内控非标、监管调查、债务和退市风险。

这类事件可在 T 日形成风险 nowcast。只有风险仍活跃、证据时间不晚于 T，且行业暴露能被明确映射时，
才允许给相关个股更高等级的 warning。

### C. T 日不可知

- 尚未公开的战争爆发或突然升级；
- 未发布的制裁/黑名单、监管调查、财务造假和业绩爆雷；
- 无先行公开迹象的技术故障、自然灾害或公司治理事件。

这类事件只能进入 `post_t_safety`，不得回填为 T 日预警，也不得据此宣称模型“提前发现”。

## 建议的 shadow warning 结构

每条 warning 至少保存：

```json
{
  "as_of_T": "YYYY-MM-DD",
  "first_public_at": "YYYY-MM-DDThh:mm:ss+TZ",
  "risk_family": "macro_calendar|holiday_gap|war_energy|trade_control|liquidity|delisting|company",
  "status": "scheduled|active|resolved",
  "severity": "med|high",
  "scope": "market|industry|stock",
  "affected_industries": [],
  "direction_certainty": "uncertain|negative",
  "why": "截至T日可核验的简短因果链",
  "source_urls": [],
  "post_t": false,
  "shadow": true
}
```

证据纪律：

1. 至少一个官方或事件主体来源；高等级市场警示再要求第二个独立来源/独立 origin。
2. 新闻转载同一篇稿件只算一个 origin，不能用转载数量制造“多源确认”。
3. `first_public_at > T` 的内容必须隔离到 `post_t_safety`。
4. “未搜到”不等于“没有风险”；搜索失败、反爬和低信息密度必须显式记录。
5. 预警只描述风险暴露，不把事件名称机械翻译成必跌方向。

## HTML 呈现规则（拟议，尚未进入生产）

### 报告级黄色提示

用于未来 5 个交易日内的已排期高影响事件，或长假信息缺口：

> ⚠ 事件窗口（T日已知）：未来5个交易日内存在宏观发布/议息/长假闭市。方向不确定，
> 仅提示跳空与波动风险；shadow，不改分数。

### 报告级红色提示

用于 T 日已公开且仍活跃的系统性压力，并满足官方源和独立来源要求：

> ⚠ 系统性风险（T日可见）：战争/能源/流动性冲击仍在演化，已出现跨行业传导。
> 本提示不代表必跌；shadow，不改分数。

### 个股级提示

只有“事件风险 × 明确行业/公司暴露”时下沉到个股：

> ⚠ 暴露警示（T日可见）：该股所属行业与当前贸易限制/油价冲击直接相关；
> 请核对公司公告中的收入、成本和地区暴露。shadow，不改分数。

泛化的市场恐慌不得给每只股票复制同一条红色警示；否则 warning 没有区分力。

## 历史毒月的可预警性假设

以下只是依据已完成网页事件账本形成的回顾性假设，不是走样本成绩：

| 可预警性 | 月份 | 回顾性理由 |
|---|---|---|
| 较高 | 2024-06、2026-03 | 信号期已有公开的贸易/基本面压力，或战争与油价冲击仍在持续 |
| 部分 | 2024-01、2024-05、2024-08、2024-12、2026-05、2026-06 | 有已知脆弱性、排期事件或正在演化的风险，但集中止损还依赖后续消息或市场传导 |
| 很低 | 2024-07、2026-01、2026-02 | 边界月或小样本/重复信号明显；2026-02 的长假可知，但战争爆发晚于大部分信号，不能倒灌 |

其中 2026-03 是最清楚的“Web 能提前报警但不能预测跌幅”的案例；2026-02 则是最重要的反例：
春节信息缺口可以事前提示，战争本身不能在公开发生前被标成已知风险。

## 验证方案

在讨论生产接入前，必须冻结风险 taxonomy，并逐笔重建历史信号日 T 的网页可见集：

1. 对每个候选在 T 日收盘时截断搜索证据，单独保存 T+1 至检索日的安全增量。
2. 输出 warning/无 warning，但不改变分数、推荐、仓位和 verdict。
3. 用信号日/月做 cluster-aware 统计，比较 warned 与 un-warned 的止损率和胜率。
4. 同时报出 precision、recall、覆盖率、warning 后仍获胜的机会成本及置信区间。
5. 分 2024、2026、系统性冲击、行业轮动、小样本重复信号分别复核。
6. 预注册最低样本量、升级阈值和回滚条件；未完成前只允许 shadow 展示。

如果 warning 只能解释已知毒月、却同样频繁警告正常月，它没有生产价值。验收重点不是“故事讲得通”，
而是在无前视证据上对未来止损是否有稳定、可校准的增量区分力。

## 官方可机读/可核验的监控种子

- 国家统计局统计信息发布日程与数据发布页；
- 中国人民银行 LPR/货币政策公告；
- 中国证监会、上交所、深交所公告与风险提示；
- 上交所融资融券汇总数据；
- 美联储 FOMC 日程和声明；
- 欧盟委员会贸易防御公告；
- 美国商务部 BIS 出口管制与 Entity List 公告。

这些来源适合作为搜索种子，不代表所有条目都会构成负面 warning。
