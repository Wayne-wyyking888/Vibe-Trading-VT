## 为什么不能把一根难看K线直接判成出货

该书目录把“巨阴、阴雨连绵、假阴高开、冲高回落、支撑线/技术关口”列入洗盘或空头陷阱，
同时又把“避雷针、倾盆大雨、死亡穿越、平台跳水、高位横盘/打压、多头陷阱”列入出货。
这意味着形态本身存在同形异义。v0.4 固定要求三个层次：

1. 位置/阶段：此前平台、前期拉升、相对指数或均线结构；
2. 行为代理：破位、上影冲高回落、连续放量阴线、高开失败等；
3. 截至信号日 T 的确认：关键位没有收回、下行结构仍在或继续跑输指数。

同时加入“假突破已经收回”和“下探针已经收回”两个洗盘/试盘豁免。豁免只会少否决，不会把股票
升级为买入；最终买入仍由原引擎和 Agent②/③决定。

## 公开章节到代理规则的映射

|研究代理|公开目录中的对应主题|机械化重点|刻意不声称|
|---|---|---|---|
|B1 平台破位未收回|整理形态、支撑线洗盘、平台跳水、多头陷阱|先有窄平台，后放量收盘破位，T仍未收回|不能判断是谁卖出|
|B2 避雷针/冲高回落确认|冲高回落洗盘、避雷针出货、技术关口多头陷阱|触及前高、长上影、放量，T仍低于事件收盘|单根长上影不自动否决|
|B3 倾盆大雨+死亡穿越|倾盆大雨、死亡穿越|多根放量阴线、累计急跌、短均线近期死叉且未修复|不把普通缩量阴跌当出货|
|B4 前期拉升后的高位派发延续|高位横盘、横盘震荡、高位打压、反转形态|先有可观拉升，再深回撤、上方成交密集且高低点下移|不把所有深跌股都视作派发|
|B5 借指数洗盘的反证|指数回调洗盘、逆势强势股、借助指数洗盘破绽|若真是借指数洗盘，个股不应长期显著弱于指数；显著跑输只作第二证据|相对弱势单独不否决|
|B6 高开探天反复失败|假阴高开洗盘、开盘探天出货|重复高开后收阴/收于前收下、放量，T仍低于事件收盘中位数|日线不能还原尾盘与分时路径|
|E1 空头陷阱收回|技术关口/支撑线/形态洗盘、空头陷阱破绽|下破后重新站回原支撑|只作 fail-open 豁免|
|E2 下探针收回|试盘特征、单针/金针式探底框架|下探前低、长下影、放量，T不低于事件收盘|只作 fail-open 豁免|

## 本版明确不做的内容

- “犬牙形态”、尾盘冲高、盘口挂单等需要分时/逐笔数据，日线无法可靠复原；
- 借公告、年报、题材、研报出货需要 point-in-time 信息语料，继续由 Agent②按 T 日证据处理；
- 不使用“庄家已建仓/正在出货”作为标签，也不把价格成交量相关性写成操纵因果；
- 不以五个已知暴雷反推阈值，不搜索连续参数，不允许单一形态直接 veto。
