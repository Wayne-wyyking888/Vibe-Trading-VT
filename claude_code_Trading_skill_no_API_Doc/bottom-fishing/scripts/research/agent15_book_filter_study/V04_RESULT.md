## 书籍信息如何进入 v0.4

本版没有复用 F1—F5。它根据《庄家的破绽》公开目录中同时存在的洗盘/试盘与出货主题，冻结了：

- B1 平台破位未收回；
- B2 避雷针/冲高回落未修复；
- B3 倾盆大雨并伴死亡穿越；
- B4 前期拉升后的高位派发延续；
- B5 借指数洗盘的反证；
- B6 反复高开探天失败；
- E1 空头陷阱收回、E2 下探针收回两个 fail-open 豁免。

核心不是把“难看K线”机械当出货，而是要求“阶段 + 形态 + 截至T确认”，且至少两类 B 同时命中；
已收回的空头陷阱/探底针不能否决。公开来源和逐章翻译边界见
[V04_BOOK_TRANSLATION.md](V04_BOOK_TRANSLATION.md)。精确数值是本研究的代理阈值，不冒充书中原公式。

## 为什么书籍规则没有形成过滤器

开发期单项命中数如下：

|代理|命中数|win|stop|timeout|
|---|---:|---:|---:|---:|
|B1|126|73|38|15|
|B2|20|13|4|3|
|B3|0|0|0|0|
|B4|588|380|156|52|
|B5|497|312|143|42|
|B6|0|0|0|0|
|E1|1,225|720|401|104|
|E2|129|74|42|13|

问题有两层：

1. E1 在抄底候选里过于常见，作为全局豁免将大部分复合命中 fail-open；B3/B6 又严格到零命中。
   这是设计可用性失败，必须原样报告，不能在看到结果后放宽阈值仍称 v0.4。
2. 即使事后完全移除 E1/E2，只作诊断，书籍形态仍没有区分力：
   - 最好的 `B1_AND_B5` 只删28笔，暴雷率 `-0.084pp`、EV `+0.015pp`；
   - `B4_AND_B5` 删244笔，暴雷率反而 `+0.475pp`、EV `-0.067pp`；
   - `COUNT_GE_2` 删303笔，暴雷率 `+0.361pp`、EV `-0.050pp`。

后面这组是看过结果后的敏感性诊断，不能作为替代规则；但它说明失败并非只由 E1 写宽造成。
