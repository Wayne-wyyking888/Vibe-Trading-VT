## 目标与数据隔离

调参集固定为生产 `bottom_shadow_log.jsonl` 中同时满足：

- `cooldown=false`；
- `judge ∈ {✓, ?, ✗}`；
- Agent 1.5 特征可计算；
- outcome 已成熟，即 `win / stop / timeout`。

预计共 61 笔，其中 `✓` 25 笔（19 win / 5 stop / 1 timeout）。核心目标是减少 `✓` 中的 stop，
但必须限制误杀赢家，禁止用“全拒绝”取得零雷率。

候选选择阶段不得读取任何 2024—2026 全局统计。选出唯一候选并冻结 ID 后，才允许打开：

1. 完全不施加冷却的全局原始过线；
2. N=5 全局推荐线；
3. 2024、2025、2026 分年；
4. `T < 2026-07-13` 的 pre-shadow 非重叠历史。

pre-shadow 是与调参事件不重叠的反向时间验证，不是未来前瞻 holdout；真正确认仍须依赖尚未发生的新 shadow 样本。

## “全部组合”的机械定义

对 F1—F5，每个家族选择“不启用”或一个变体；至少启用一个家族。若启用 n 个家族，枚举
`k=1..n` 的全部 `k-of-n` 否决门。总候选固定为 50,764 个。缺历史时 fail-open。

v0.1 的 `F2 OR F4 OR 总异常数≥2` 不是单一 k-of-n，因此作为独立基准精确复现，不混入 v0.2 网格。

## 调参硬约束与唯一选择顺序

候选必须同时满足：

- `✓` 成熟样本保留率≥60%；
- `✓` 赢家保留率≥75%；
- 全部有裁定成熟样本保留率≥60%；
- 全部有裁定赢家保留率≥75%；
- 至少过滤1笔 `✓ stop`。

合格候选按以下固定字典序选唯一第一名：

1. 过滤 `✓ stop` 数最多；
2. 误杀 `✓ win` 数最少；
3. 过滤全部裁定 stop 数最多；
4. 误杀全部裁定 win 数最少；
5. `✓` 过滤后 EV 最高；
6. 启用家族数最少；
7. k 最大；
8. `candidate_id` 字典序最小。

严禁查看全局结果后改选排行榜第二名或改网格。
