## Shadow 网格与反全拒绝约束

每个家族可不启用或选择一个变体；至少启用一个。启用 n 个家族时枚举全部 `k=1..n`，固定
**523,864** 个候选。

候选只按校准集标签接受或拒绝，并必须同时满足：

- `✓` 成熟样本保留率≥60%，且误杀 `✓` 赢家不超过5笔；
- 全部有裁定成熟样本保留率≥50%，全部有裁定赢家保留率≥60%。

修订 A 后如果仍没有合格候选过滤5/5，不得在看到结果后再次放宽约束；报告约束内最大可过滤数。

## 唯一选择顺序

合格候选只按 shadow 校准指标固定排序：

1. 过滤 `✓ stop` 数最多（目标5/5）；
2. 误杀 `✓ win` 最少；
3. 过滤全部有裁定 stop 数最多；
4. 误杀全部有裁定 win 最少；
5. `✓` 过滤后 EV 最高；
6. 启用家族数最少；
7. k 最大；
8. `candidate_id` 字典序最小。

## 冻结后的逆时间验证门禁

唯一规则冻结后，才计算 N=5 实际候选的2024、2025、2026截至07-12及合计指标。只有同时满足
下列条件，结论才可标为 `eligible_for_new_forward_shadow_not_production`：

- 五个 `✓ stop` 全部过滤；
- 合计成熟样本保留率≥60%，误杀赢家占比≤25%；
- 合计暴雷率至少下降3.00个百分点、胜率至少提高1.00个百分点、EV至少提高0.50个百分点；
- 2024、2025、2026截至07-12各自暴雷率不恶化，且各自成熟样本保留率≥50%；
- 2,000次月份块 bootstrap：暴雷率变化95%区间上界<0，EV变化95%区间下界>0。

任一项失败即为 `fails_v03_historical_validation_research_only`，不得转生产。即使全部通过，也必须冻结规则，
在以后新增的 N=5 实际候选上累计至少30笔成熟 prospective shadow，再单独评审是否进入生产。
