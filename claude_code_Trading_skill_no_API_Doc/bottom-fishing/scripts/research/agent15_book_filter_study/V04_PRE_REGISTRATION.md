# Agent 1.5 v0.4：引擎候选风险过滤器重建预注册

冻结时间：2026-09-11（北京时间口径）  
状态：**新假设、研究专用；不修改生产引擎、skill、state、Agent②/③或交易字段**。

## 1. 研究对象与实际插入位置

v0.4 不再围绕 v0.2/v0.3 的 F1—F5 或五个已知 `✓ stop` 调参。它从《庄家的破绽》公开目录中的
洗盘/试盘/出货对照重新定义六个阶段化日线代理，只回答：在现行抄底引擎已经过底部区、双路径绝对分数及 `ATR<=4` 后，
能否对 **N=5 旋转门放行的未冷却候选** 再做一次有稳定增量的硬否决。

固定生产顺序为：

`原始过线 -> 同股原始过线刷新N=5旋转门 -> cooldown=false候选 -> Agent 1.5 -> Agent②/③`

因此本研究的唯一主母体是 `signals_cooldown5.csv.gz`；无冷却原始过线只用于核对旋转门，不参与
v0.4 选型。即使 Agent 1.5 否决，原始过线仍已刷新冷却时钟，不能借过滤器绕过旋转门。

## 3. 书籍映射与冻结前修订 A

用户在首次运行前要求更忠实地借鉴《庄家的破绽》，故在尚未计算任何 v0.4 特征结果时做修订 A：
撤销原通用 G1—G6，改为 B1—B6“阶段+形态+截至T确认”，并加入 E1/E2 洗盘/试盘豁免。
公开来源、章节映射、无法由日线表达的内容及解释边界详见 [V04_BOOK_TRANSLATION.md](V04_BOOK_TRANSLATION.md)。
精确阈值是研究代理，不冒充书中原数值；本修订后不再改参数。

### B1：平台破位仍未收回

- 最近10日内，某事件日前20日振幅/收盘中位数 `<=15%`；
- 事件日收盘低于该平台最低价至少 `1%`，且成交量 `>=` 平台20日中位数的 `1.20` 倍；
- T日收盘仍不高于原平台最低价。

### B2：避雷针/冲高回落仍未修复

- 最近10日内，事件日最高价触及此前20日最高价的 `99.7%`；
- 事件日收盘不高于前高，上影/振幅 `>=45%`，量/此前20日中位量 `>=1.50`；
- T日收盘不高于事件日收盘。

### B3：倾盆大雨并伴近期死亡穿越

- 最近5日收盘累计收益 `<=-6%`，至少2根 `C<O` 阴线；
- 这些阴线成交量中位数/此前20日成交量中位数 `>=1.20`；
- MA5 在最近5日由不低于 MA10 下穿至低于 MA10，且 T 日仍 `MA5<MA10`。

### B4：前期拉升后的高位派发延续

- 最近120日先出现从此前低点到峰值 `>=30%` 的拉升，T较该峰值回撤 `>=20%`；
- 20日典型价成交量加权均价高于 T 收盘至少 `0.75 ATR`，且典型价高于 T 收盘的成交量占比 `>=65%`；
- 最近10日最高价和最低价均不高于此前10日各自水平的 `99%`。

### B5：借指数洗盘的反证

- 个股20日收益减创业板指20日收益 `<=-8` 个百分点；
- 个股20日收益 `<=0`；B5只作第二证据，不能单独否决。

### B6：反复高开探天失败

- 最近10日至少2日开盘较前收 `>=1.5%`，但 `C<O` 且 `C<=前收`；
- 对应日成交量/各自此前20日中位量 `>=1.20`，上影/振幅 `>=30%`；
- T日收盘不高于这些事件日收盘的中位数。

### E1/E2：洗盘或试盘已经收回时 fail-open

- E1 空头陷阱收回：最近10日曾下探此前20日支撑，T日重新站上该支撑 `0.5%` 且不低于事件收盘；
- E2 下探针收回：最近10日曾下探此前20日低点、下影/振幅 `>=45%`、量比 `>=1.20`，
  且T日不低于事件收盘；
- 任一豁免成立时，所有 B 组合都 `keep`。豁免不构成买入加分。

## 4. 小候选集与空模型

不搜索连续阈值，不复用 v0.2/v0.3 宽松变体，也不允许单根形态直接否决。候选固定为18条：

1. `KEEP_ALL` 空模型；
2. 任意两个不同 B 的 AND，共15条；
3. `COUNT_GE_2` 与 `COUNT_GE_3` 两条等权计数门；
4. 所有17条非空规则均先应用 E1/E2 fail-open 豁免。

`KEEP_ALL` 不参与非空规则排名；若没有非空规则通过稳定性门禁，它自动成为 v0.4 的正式选择，
含义是“当前没有证据增加技术面否决”，而不是研究失败后另挑一条好看的规则。

## 6. 开发期门禁与唯一排序

每条非空候选先在全部开发期和五个时间块上计算。只有同时满足以下条件才可入围：

- 全开发期成熟样本保留率 `>=70%`；
- 误杀赢家占全部赢家 `<=20%`；
- stop 捕获率减赢家误杀率 `>=5` 个百分点；
- 保留后 stop 率至少下降 `1.0pp`，EV 至少增加 `0.10pp/笔`；
- 五块中至少三块 stop 率不升且至少三块 EV 不降；
- 任一块 stop 率不得恶化超过 `1.0pp`，EV 不得恶化超过 `0.15pp/笔`。

入围者按以下顺序唯一排序：

1. 五块中最差 stop 率变化最小；
2. 五块中最差 EV 变化最大；
3. 全开发期 stop 率降幅最大；
4. 全开发期胜率增幅最大；
5. 全开发期 EV 增幅最大；
6. stop 捕获率最大；
7. 赢家误杀率最小；
8. 使用的 B 项更少；
9. `candidate_id` 字典序。

同时对唯一规则做5,000次信号月份块 bootstrap；这是选择后不确定性审计，不把选择后的普通区间伪装成
已校正多重检验的显著性。

## 7. 锁定审计、shadow 与生产边界

- 唯一规则冻结后才计算 07-13以后准OOS整体、按月、按 `✓/?/✗` 和五个已知 `✓ stop` 的结果；
  后三项仅审计，不反向改规则。
- 无论准OOS数字多好，本轮都不能直接改生产：该窗口已污染且当前只有约67笔成熟事件。
- 若非空规则通过开发门禁，只能从 `T>2026-09-09` 开始原规则 prospective shadow；Agent②仍需对
  被1.5影子否决的候选做反事实裁定，避免丢失机会成本标签。
- 讨论生产至少要求：100笔成熟、覆盖至少6个自然月；成熟保留率>=70%、赢家误杀<=20%、stop率不升、
  EV不降；月份块 bootstrap 的 stop 变化上界<0且EV变化下界>0。任何期间不得调阈值或换候选。
- 若开发期无非空入围者，v0.4 固定为 `KEEP_ALL`，不启动技术面硬否决；Agent②基本面恶化否决和现有
  月度/滚动风险预算继续承担正交风险控制。
