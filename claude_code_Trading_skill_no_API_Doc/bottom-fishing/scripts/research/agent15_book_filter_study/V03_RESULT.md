## 先说结论

按“先过滤 `✓ stop` 数最大，再保留 `✓ win` 数最大”的优先级，并接受最多误杀5个 `✓ win`，
v0.3 在61笔 shadow 校准集上确实过滤了5/5笔已知打勾暴雷。但是规则冻结后，它在
2024—2026-07-12 的1,770笔 N=5 实际成熟候选上没有泛化：胜率下降1.043个百分点、暴雷率上升
0.778个百分点、EV下降0.114个百分点。主要失败来自2024。

因此这条规则不能进入生产，也未达到“进入新增 prospective shadow”的预设门禁。它证明了
F1—F5现有价量特征可以事后包住五雷，但没有证明它能稳定区分未来暴雷与赢家。

## 冻结选择

523,864个组合中，376,044个通过修订A后的反全拒绝约束；48,950个组合能过滤5/5，24个同时通过
约束。唯一第一名是：

`F1=-;F2=F2_B10_GPOS050;F3=F3_V150_E025;F4=-;F5=F5_R06_D01_V060;k=2`

含义是以下三项至少命中两项即由 Agent 1.5 否决：

- F2：20日阳线至少10根，末5日与前5日典型价中位数之差不高于 `+0.50 ATR`；
- F3：近10日峰值量比至少1.50，价格效率不高于0.25，10日收益不高于2%；
- F5：近10日峰值相对前低反弹至少6%，随后回撤至少1%，峰值量比至少0.60。

其中 F2 允许重心上移、F5量比阈值低于1，都属于为已知漏网案例增加的宽松包络，不能说成书中的
原始硬规则。
