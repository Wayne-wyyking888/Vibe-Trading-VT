# 30*（20%涨跌幅）独立机制研究：预注册

冻结日期：2026-08-08。本文在查看本实验新抓取数据的结果前写定；任何事后修改都必须在结果中显式标为
`post_hoc`，不能冒充预注册结论。

## 研究问题

股票池固定为当前成交额前 600 只沪深 A 股中的 `60* / 00* / 30*`，排除 ST、退市整理和数据不足股票。
`60* + 00*` 属于 10% 涨跌幅组，始终使用生产基线；只为 `30*`（20% 涨跌幅组）研究独立的打分语义、
ATR gate 和阈值。生产 workflow、权重、JSON、影子日志和报告都不修改。

股票池仍有“今日高流动性股票回看历史”的幸存者偏差，不能把绝对胜率外推为真实可交易收益。

## 固定数据与标签

- 数据：腾讯免费前复权日 K，最多 900 根；创业板指 `399006` 作市场状态；每次运行记录 URL 族、抓取时点、
  数据 hash、引擎 hash、股票池和失败清单。
- 报告窗：信号日 `2023-11-01` 起，到每只股票拥有完整未来 21 根 K 线（T+1 进场 + 20 日观察）为止。
- 底部区：`dd60 <= -20` 且 `pos60 <= 25`，与生产一致。
- 主要标签：T+1 开盘进场；买入日收盘 `<= -8%` 先判 stop；其后每天先判 low `<= -8%`，再判
  high `>= +5%`；20 日无果为 timeout。这是旧研究真实口径，不用期末收益替代。
- 主指标：胜率、暴雷率（先触 -8%）、`EV_proxy = 5% * win_rate - 8% * stop_rate`。
- 补充深尾：进场后 20 日内最低价是否触及 -15%；只用于风险描述，不参与选参。
- 旋转门：N=5；同票距上次“原始过线”不超过 5 个本票交易日则压下；压下的过线也刷新计时。
- 冷却预热：从 2023-10-01 开始生成信号，正式统计从 2023-11-01 开始，避免窗口首日漏掉此前过线。

## 候选机制（只作用于 30*）

不训练树模型，不引入资金流、MA250、K 线形态等已被否决的因子，也不重新拟合连续权重。沿用现有离散
权重，只探索与 20% 日涨跌幅制度直接相关的因子语义和 gate：

1. `legacy`：完全沿用全市场语义（20 日内涨幅 >=9.3% 即“涨停基因”、低开 2% 收回、ATR>=7 惩罚、
   回撤甜区 -45~-30、RSV 20~40）。
2. `limit20`：仅把 30* 的“涨停基因”改为单日涨幅 >=18.5%。
3. `limit20_atr10`：在 2 上把 ATR 高波惩罚阈值改为 10；ATR gate 仍由网格单独控制。
4. `scaled20`：在 3 上把低开收回阈值改为 3%、回撤甜区扩为 -50~-30、RSV 修复扩为 20~45。
5. `scaled20_rsv40`：与 4 相同，但保留 RSV 20~40，用来隔离 RSV 扩窗影响。

每种语义只使用原权重。网格固定为：

- ATR cap：3.5 / 4.0 / 4.5 / 5.0 / 5.5 / 6.0 / 7.0 / 8.0
- 防守日总分阈值：16 / 18 / 20 / 22 / 24
- 非防守日个股分阈值：13 / 15 / 17 / 19 / 21

基线 `legacy + ATR<=4 + 防守18/非防守15` 必须在候选表中。

## 时间隔离与选择规则

- discovery：2023-11-01 至 2024-12 年末前 21 个指数交易日。
- validation：2025-01-01 至 2025-12 年末前 21 个指数交易日。
- final holdout：2026-01-01 起的全部成熟标签；在候选冻结前不可查看或参与排序。
- 年末留下 21 个指数交易日 embargo，防止某段末尾的 T+1/20 日标签用到下一段价格。

候选进入排序池需同时满足：

- discovery、validation 各自信号数不少于 `max(60, 对应基线数量的 50%)`；
- validation 暴雷率不高于基线 +2pp；胜率不低于基线 -2pp；EV 不低于基线 -0.25%/笔。

排序为预先固定的字典序：

1. `min(discovery EV, validation EV)` 越高越好；
2. `max(discovery 暴雷率, validation 暴雷率)` 越低越好；
3. discovery/validation 平均胜率越高越好；
4. 两段总信号数越多越好；
5. candidate_id 字典序，确保完全确定。

若只有基线通过，选中基线，研究结论为“未找到值得拆分的 30* 机制”，不能降低门槛凑结果。

## 最终判断门槛

选中机制只在一次性 2026 holdout 上与 30* 基线比较，并同时拼回未改动的 `60*+00*`，报告：

- 30* 与全组合的胜率、暴雷率、EV、信号量、月度/半年分布、Wilson 95% CI；
- 按月份簇 bootstrap（5000 次，seed=20260808）的指标差 CI；
- 机会成本（信号保留率）和 -15% 深尾率。

“值得进入 shadow 讨论”须同时满足：

1. 30* holdout EV 不低于基线；
2. 30* holdout 胜率至少 +2pp，或暴雷率至少 -2pp；
3. 合并 `60/00/30` 后 holdout EV 不低于统一基线；
4. 信号保留率 >=50%；
5. discovery、validation、holdout 三段中至少两段 EV 优于基线，且没有一段暴雷率恶化超过 5pp。

满足也只意味着可进入生产外 shadow 复验，不代表直接修改 skill；月簇 bootstrap CI 若跨 0，必须写明统计证据不足。
