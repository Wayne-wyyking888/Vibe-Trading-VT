# bottom-fishing 节假日事件研究

本目录归档“2024—2026年A股法定节假日前后与抄底推荐线爆雷率”的可复现研究源码。
它是研究层实验，不是生产 workflow 的一部分。

## 文件

- `holiday_calendar.csv`：上交所年度休市通知整理出的20个市场闭市事件。
- `holiday_event_study.py`：事件窗口、5交易日冷却、成熟标签、局部连续窗口随机化、
  节日 cluster bootstrap、分年/长短假/毒月剔除、毒月反向归因及T+1真实进场日复核。
- `SOURCE_MANIFEST.json`：源码、官方来源、外部 parquet 与本次输出的 hash。

大样本 parquet 仍放在 `C:\Trading_analysis\research\bottom_ml\`，运行结果写入
`C:\Trading_analysis\research\bottom_holiday_event_study\output\`，不复制大文件进 skill。

## 固定口径

1. 推荐线不变：防守日总分≥18，或非防守日个股分≥15；两条路径均须ATR≤4。
2. 标签不变：T+1开盘进场；20交易日内先+5%为胜，先-8%为雷。
3. 同时报原始过线与当前5交易日旋转门冷却；被冷却的过线也刷新计时。
4. 只保留已经完整走完“T+1+20交易日”标签窗的信号，避免样本尾部只剩快速输赢。
5. 信号日T与真实进场日T+1分别检验，防止把节前最后一个信号误当成节前买入。
6. 主对照在每个节日同侧10交易日内完成：相邻1/3/5日与其余日期比较，并随机移动
   等长连续窗口；区间以节日事件为cluster bootstrap单位。
7. 逐笔/全样本率只作描述，不能替代事件级推断；逐节日拆分、分年、长短假、剔除毒月
   和留出期2026共同检查稳定性。

## 本次结论（2026-07-23）

- 成熟样本：原始推荐线4468笔，当前5日冷却线1455笔。
- 20个官方闭市事件中，16个具备完整因子预热、节前后局部对照和成熟标签。
- 当前冷却线按信号T计：节前5日雷率21.9%，局部前序对照14.0%，差`+7.9pp`；
  但节日cluster 95%区间为`[-6.9,+21.0]pp`，随机化`p=0.470`，BH `q=0.765`。
- 节后5日：21.3% vs 局部后序对照16.5%，差`+4.7pp`，`p=0.809`。
- 按真实T+1进场日复核：节前5日差`+5.7pp`（`p=0.255`），节后5日差`-4.8pp`
  （`p=0.211`）；方向不支持稳定的节后风险。
- 2024/2025/2026、长假/短假及逐节日结果不稳定；2026留出期节后方向与发现期相反。

### 毒月 × 节假日反向归因

不能只检验“剔除毒月后节日效应是否存在”，还必须反过来删掉节日前后窗口后重算毒月：

- 原始推荐线10个毒月中，±5日节日窗占25.5%的信号、贡献26.1%的雷；窗内雷率55.8%，
  非节日窗53.9%，只有`+1.9pp`。
- 当前5日冷却线7个毒月中，节日窗占27.7%的信号、贡献28.8%的雷；窗内52.0%，
  非节日窗49.4%，只有`+2.6pp`。
- 月级“有节日信号的月份是否更容易成为毒月”：原始线Fisher `p=0.665`、OR=0.64；
  节日信号占比与月雷率Spearman=-0.092（`p=0.667`）。冷却线Fisher `p=0.603`、
  Spearman=-0.244（`p=0.314`）。
- 删除±5日窗口后，原始线7/10个毒月仍满足原定义；另3个月只是剩余样本降到n<15，
  其非节日窗雷率仍分别为100%、66.7%、77.8%，不能算被节日过滤“治愈”。
- 冷却线6/7仍为毒月；消失的2026-02同样只是n降到5，非节日窗雷率反而80%。
- 1/3/5日三档、原始线/冷却线两口径下，**真正因删除节日窗后n仍≥15且雷率跌破30%的毒月均为0**。
- 2024-06是最强反例：节日窗占61.3%的信号、57.8%的雷，窗内雷率65.3%，低于
  同月非节日窗75.5%；删除节日窗后仍是毒月。
- 原始线删除节日窗后反而新增2024-09为毒月，说明该月节日窗在稀释而不是制造风险。

反向裁定：**日历重叠不等于因果；毒月不能归因于节假日窗口。**

裁定：**节前风险只有弱提示，尚无稳定、显著、可部署的节假日效应；节后暴雷相关性不成立。**
不得据此增加生产禁买窗口或改数值规则。若继续观察，只能作为shadow日历标签累计未来节日样本。

限制：当前股票池有幸存者偏差，只有16个完整事件；2024元旦受60日因子预热影响，
2026端午及之后尚未完整走完20交易日标签窗。“实际跨假期持仓”以节前仍存续为条件，
存在存续选择，只能用于风险描述。
