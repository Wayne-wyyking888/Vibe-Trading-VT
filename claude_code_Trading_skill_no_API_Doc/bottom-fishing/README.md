# bottom-fishing — 抄底扫描引擎（研究存档 + 使用说明）

一句话：**在防守市里买"已开始修复的适度超跌票"**，与 weekly-ashare-rank（进攻市动量）互补。
诞生于 2026-07-14 的可行性研究（先测后写，全部规则有面板证据）。

## 用法
```powershell
python "C:\Trading_analysis\Vibe-Trading-VT\codex_acceptance\run_engine.py" bottom --            # T日扫描
python "C:\Trading_analysis\Vibe-Trading-VT\codex_acceptance\run_engine.py" bottom -- --review   # 影子对账
```
无参数设计：阈值是研究定版，改动须先过走样本（见下）。

## HTML 中的 ETF 持仓信息块（2026-08-02）

每只最终裁定候选的 F10 下方会附加一个独立的“ETF持仓与走势相似度”区块。初扫 JSON/HTML 固定不含 ETF，
避免 Agent②/③在取证与裁定时看到它；模块只在 Agent②/③完成、原 renderer 生成裁定版后运行，
固定 `used_in_recommendation=false`，因此不进入 Agent①量化、Agent②裁定或 Agent③预警，也不改变候选、分数、
✓/?/✗、排序、价位、仓位和熔断。公开数据失败时仅本区块降级，推荐流程继续保持原结果。

“持有该股的 ETF”采用东方财富公开机构持仓库的**最近完整报告期**，排除联接基金；完整名单只保留在结构化 JSON
供审计，HTML 不提供全部展开表。基金披露是
季度/半年度/年度口径，不是盘中实时仓位，一/三季报也可能不是全量持仓。较新的未完整报告期只作提示，不与完整期
混用。走势排名只在按持仓占净值排序的前80只 ETF 中计算，以股票 T 日为截止，取最近60个共同交易日的前复权
日对数收益 Pearson 相关系数降序，同分按归一化路径 RMSE 升序；HTML 只显示最相关前5只。

实现与验收位于 `codex_acceptance/bottom_etf.py`、`test_bottom_etf.py` 和 `acceptance.py`；缓存位于
`C:\Trading_analysis\data\cache\ashare_weekly\bottom_etf`。持仓页面口径说明：
`https://data.eastmoney.com/zlsj/jj.html`。

## 方法论（研究链摘要，面板=476股×401日≈19万股票日，赛跑口径=T+1开盘进场后先到+X%还是先砸-8%）

1. **底部区** = 距60日高点回撤≥20% 且 60日位≤25（占全部股票日10.9%，基线胜70.6%/雷22.9%）。
2. **有效因子（全是"修复确认"类）**：防守日+8.6pp、站回MA10+5.2、DIF3日向上+4.5、低开2%收回+4.4、
   RSV超卖回升20-40 +3.9、回撤30-45%+3.7、站回MA5+3.7。
   **反指标（"越惨越买"类）**：深超卖RSV≤15 -7.4、≥4连阴-6.3、20日涨停基因-5.4、ATR≥7 -3.5、刚创新低-3.1、
   W底右脚=安慰剂。K线企稳形态(缩量阳/放量反包/长下影)全部无增量——**形态识底是玄学，实证判死**。
3. **推荐线（双路径）**：防守日·总分≥18 ∥ 非防守日·个股分(去防守项)≥15，均须 **ATR≤4**。
   走样本(前250天训/后90天测,测试窗含2026年6-7月退潮)：**胜75.2~77.8% / 先砸-8%=13.8~13.9% / EV≈+2.7%/笔，几乎无衰减**。
   对照：多元LPM学权重 OOS 64.9%≈随机全灭（学了反弹市的"急跌放量就买"）——**手工稳健dummy>复杂拟合，勿改回学习器**。
4. **拆档**（推荐线n=969）：先到+5%=75.2%(vs -8%)、+10%=51.1%、+20%=18.6%(胜≈雷)、+30%=7.8%(负期望彩票)；
   触-10%=12.1%、-15%=4.1%；**EV最优目标=+10%(+3.71%/笔)**，默认+5%落袋半仓/+10%清。
   持有越久均值越高(3天+1.69%→30天+13.17%)——**抄底要长拿(≤20日)，与动量"要短拿"相反**。
5. **Top-1判死**："每天选相对最好的1只"=随机（69.2% vs 随机67.7%）；"选回撤最深"=逆向选择(44.3%先砸)。
   **只认绝对阈值，0过线=空手**（历史约6成日子无票）。
6. **已否决勿再试**：资金流(新浪历史11649行——单变量+5pp但叠到打分上反向：≥18+强流出74.7%反而最好，与P11自洽)、
   基本面打分(无历史PIT不可回测,只做F10 veto+错杀人工判断)、"刚崩1-3天=毒"规则(OOS 73.7/17.1差于旧线,不采纳)。
7. **已知未解风险**：月度爆雷成簇（2026-02达55%）；网页事件复核显示共同点更像跨行业 regime 切换，
   不是固定板块或节假日单因果，且部分外生冲击在信号后才公开、无法事前预知。生产防御仍是月度预算
   (账户-3%停做)与滚动雷率熔断；Agent③ Web nowcast 只作 shadow warning；
   跌停封死 → 单票≤3.5%硬上限。**影子候选因子**（强格子但按"OOS只用一次"纪律未进规则，随影子日志复验）：
   防守持续≥9天(82.3%/13.6%)、大盘RSV∈[15,40](77.7%/16.1%)。
8. **水分声明**：400天净上涨窗口(随机基线本身65%)+股票池=今日成交额前600的幸存者——绝对数字打七折，相对结构可信。

## 毒月专项研究（2026-07-14，扩展面板 2023-11~2026-07·660交易日·488股·推荐线4505笔）
- **分年（2024=真样本外）**：2024 全年 **51.6%胜/42.7%雷/EV-0.84%（亏钱）**；2025 78.3%/10.8%/+3.05；2026 73.3%/21.6%/+1.94。
  本策略市况依赖：2025-26 的 edge 在 2024 式阴跌熊市不存在。
- **毒月清单口径修正（2026-07-23）**：当前固定面板为10个严格毒月；2024-07雷率29.9827%，只作为旧研究边界月，
  不再冒充≥30%的严格毒月。
- **集中性解剖口径修正**：旧“61%”按5个**有信号日期**滚动，可能跨越超过5个真实交易日。按连续5个市场交易日重算，
  10个严格毒月的止损兑现窗覆盖506/884=57.2%；含2024-07边界月为584/1057=55.3%。②个股——旧面板78%重复率
  （1075笔雷来自237只：止损后又过线又雷的旋转门）；③特征——**毒月输家与赢家、与正常月输家的个股特征完全相同**
  （总分22vs22、ATR3.2vs3.3、回撤-26.5vs-26.9），唯一差异在市场端：毒月雷=防守已11天+大盘RSV20+大盘随后10日再跌-3.2%。
  **结论：毒月=「跌久必反」赌注失败的月份，选股端无解。**
- **牛熊闸门(MA250)否决**：聚合看年线上73.5% vs 年线下54.1%分离巨大，但2024·年线上子样本 **29.6%胜/48.8%雷全场最差**
  （2024年5月式假突破）——分离度纯属"2024 vs 2025-26"的regime混淆，无前瞻防护力，不采纳。
- **防御定版（唯二有效，都是预算型熔断）**：月度亏损-3%停做 + 滚动停做开关（--review 自动：近20笔雷率≥30%→停）。
- **崩盘快刀适用性**：过线票买入日崩(收≤-5%)概率仅0.5%(24/4498)；崩后持有 21%胜/79%雷/EV-5.29% vs 次日出-5.58%
  ——期望打平，保留（截尾+跨skill纪律统一，成本≈0）。
- **行业复核补齐（2026-07-23）**：大样本毒月没有“同一板块居多”的稳定共同点，主要是跨行业 regime 冲击；
  2026-01/05/06 等小样本月份容易被单股重复信号或赛道轮动放大。旧单次抓取的2023大部分仍在窗外
  （腾讯个股单次返回约640根；更早历史须像 `board30_split_study` 一样分段补取并核对重叠复权价）。

### Agent③ 毒月 Web 风险 nowcast（2026-07-23 接入生产流程，shadow-only）

毒月事件研究和节假日研究支持“可预警风险”而不支持“预测毒月”：

- 节假日不是毒月根因：毒月内±5日窗占25.5%信号/26.1%雷，删除窗口后因雷率跌破30%而消失的毒月为0；
  长假只可能放大信息缺口。
- 可提前看到的是已排期宏观/议息/政策生效日、长假闭市，以及T日已经发生且仍在演化的战争—油价、
  贸易限制、流动性和退市监管压力。
- 尚未公开的战争爆发、临时制裁名单和公司爆雷不能诚实预知；发生后只能进入T后执行安全增量。
- 历史回顾中2026-03是“可提前报警但不可预测跌幅”的代表；2026-02是反例：春节信息缺口可知，
  但后续战争不能倒灌成节前已知风险。

因此新增 Agent③：每次扫描固定覆盖五个市场风险域，将 T 日 warning 写入报告级 alert，并只对有明确行业/
产品/成本/海外收入暴露的候选下沉个股 alert。v3 要求每次把五域检索到实际完成时点，并对每条事件及五域综合
写事实、当前共识、基准/上下行情景、置信度、传导链、观察变量和失效条件；FOMC、PMI 只是事件例子，
不能只写“方向不确定”。每条重大排期 warning 还要一对一登记官方排期、北京时间、一致预期、前值和公布后观察项；
CPI 与 PPI 必须分别使用事件专属指标 ID，并补齐总项/最终需求与核心口径的环比/同比四项及口径定义，禁止混用。
五域之后还必须合并输出这些信息反映到A股下一交易日和未来1—5个交易日的大概
方向、风格与板块结构；全部市场信号和五域综合都须逐项处置，未解释项必须为0，并在顶部板块 bullet 显示简短结论。
白话结论放在最终HTML顶部“市况”正下方；不允许编造未经校准的涨跌概率或点位。数据契约为
`codex_audit.toxic_risk_warning`/`bottom-toxic-risk-warning/v3`；验收器强制检查T日截止、来源 origin、
五域 coverage、T后隔离、最新运行时点评估、A股走势映射和 HTML 可见性。当前固定 `mode=shadow`，
不改分数、✓/?/✗、仓位或熔断；
完成无前视样本、误报率和机会成本评估前不得升级为交易 gate。完整协议见
`references/TOXIC_RISK_WARNING_PROTOCOL.md`，复现实验见 `references/RESEARCH_LEDGER.md`。

### 2024修复因子测试（2026-07-14 追加，全部否决——2024是"确认信号=陷阱"的对抗性市况）
测了5个市况因子（MA60斜率>0 / 大盘250日回撤深浅 / 市场宽度>30% / 宽度5日回升 / 新低家数<5%杀跌衰竭）：
**全期聚合都"有效"，但2024内部全部反向**——MA60向上时33.9%胜(vs向下55.7%)、宽度回升时47.7%(vs未回升57.5%)、
杀跌衰竭时41.0%(vs仍杀跌58.8%)……2024的每一次"市场好转信号"都是多头陷阱（2-5月反弹后创新低），
常规确认逻辑在该市况下系统性选中陷阱入场点。**结论：毒月市况无法用市场状态因子事前过滤，聚合分离度全是
regime混淆（与MA250同病），一律不采纳。**
滚动停做开关历史仿真（无前视）：2024执行1022笔(EV-1.82)跳过1550笔——总亏损比不开关少约14%但**每笔EV反而更差**

限总量的减震器，不是alpha修复器；2024式市况的每笔期望为负是事实，正确动作是整体缩量/停做，不存在选出好笔的方法。**

### CatBoost选股 + 毒月消息面对照 双实验（2026-07-16，只读研究；源码已归档到 `scripts/research/bottom_ml/`，大样本数据仍在 `C:\Trading_analysis\research\bottom_ml\`，**未改任何数值规则**）
独立重建面板 478股×~640日 ≈ **4.4万底部区已了结样本**(2024-01~2026-07)，因子/标签逐位对齐引擎
（600415/600048 在 2026-07-15 的 dd60/atr/rsv/dd250 全部逐位一致）；全底部区 base = 66%胜/28%雷。

  分regime 每格 ML≤规则；holdout(2026-05~07) ML 57.4/41.7 vs 规则 60.2/34.3。
- **特征重要度 ≈90% 集中在大盘 regime**（idx_rsv 39.7 / idx_chg1 29.7 / def_days 20.7），个股因子(dd60/atr/rsv…)≈0
  → 量化个股特征端无信号，用更强模型+正规 purged CV 独立复现"多元学习权重OOS全灭"（第二份证据）。
  ML 唯一可能增量方向 = **regime择时（连续风险刻度盘调总仓），绝非选股**。
- 过拟合脆弱性：第一版含 dd250 曾在 holdout 虚高 71%，去掉一个低权重特征就跌回 57%——**勿信单窗口好数字**。

**实验B — 毒月消息面 8v8 对照**（输家 vs 赢家，同毒月·同高分过线，人工网页检索红旗）→ **Agent②升级「红旗分型」**：
- **事件型红旗**(减持/质押/解禁)：输家 ~3-4/8，**赢家 ~4/8**（中金减持/天通质押70%/横店东磁减持照样赢）→ **无区分力**。
- **基本面恶化型**(业绩暴雷/债务/销量断崖)：输家 4/8（欧菲光债务/新华联重整/赛力斯销量崩/中曼-86%），**赢家 0/8** → **强区分力**。
- 输家样本：欧菲光·海兰信(2024-01)、中际旭创·新华联(2025-03)、和而泰·赛力斯(2026-02)、中曼石油·东鹏饮料(2026-05)。
- ⇒ 消息面 filter 价值不在机械否决 F10 事件（赢家一样带、否了白否+误杀+常剩不下票），而在 **"恶化 vs 错杀"细分裁定**。
  已落地 SKILL step2「红旗分型」：恶化型强否决✗、事件型单独不否（叠加恶化或急性大比例才否：当日解禁≥15%+减持、质押≥55%）、
  前视纪律（只认 T 日已公开信息，滞后披露标注仅供复盘）、纯 regime 踩踏（海兰信2024-01微盘危机）免责靠仓位兜底。
- **caveat**：n=16 定性 + 前视偏差（销量/季报等恶化多为滞后披露·裁定时不可得）——进硬规则前须面板量化验证，
  当前仅作 Agent② 人工裁定 rubric，**不是新数值 gate**。

### Agent② 取证护栏 ×2（2026-07-17 加，源自 2026-07-16 宁德时代实盘裁定，**取证层·非判据层·非数值规则**）
「红旗分型」上线后的首个边界案例（T=2026-07-16 唯一过线票 300750，裁定 ?），暴露两个**取证**坑，均已进 SKILL step2 ①/⑤：

1. **F10 种子会过期 → `f10_flag` 常是误报**：引擎点亮 `⚠F10负面待裁定` 只看 `forecast.type`(预亏/预减/略减)、
   **不看新鲜度**。宁德 flag 源 = 2025-01-21"略减"公告（讲的是**2024年营收**-8.71~11.2%）、`fresh=false`、距T **18个月**；
   而同一 JSON 里 `kcfj_yoy`=+52.95%、2026Q1 营收+52.45%/归母净利+48.52%，**方向完全相反**。
   → 护栏：先核 `notice_date` 距T间隔 + `fresh`，与 `kcfj_yoy`/最新季报交叉验证；陈旧或矛盾 = 误报勿否决。
   → **根因（不是缓存脏）**：东财 `RPT_PUBLIC_OP_NEWPREDICT` 取的是"该股**最新一条**业绩预告、**无年龄下限**"。
     公司只在业绩大变动时才强制发预告，增长平稳者可以一两年不发——宁德自 2025-01 起就没再发过，**库里最新的就是它**。
   → **引擎侧已修，但只改显示不改判断**（2026-07-17，`_fc_age_tag`）：flag 文本直出年龄 →
     `⚠F10负面待裁定(预告略减·2025-01-21·541天前·⚠陈旧,须与扣非同比/最新季报交叉验证,勿据此否决)`。
     **刻意不给 flag 加 `fresh` 门槛（勿改回）**：`fresh_days=10` 窗口太紧，**20天前的预亏照样重大却 fresh=False**，
     加 gate 会让 flag 不亮 → Agent② 不去看 → **漏报，比误报危险**。flag 本就是"待裁定"提示器、不进打分/推荐线，
     故正解 = 保留"任何负面预告都亮" + 把年龄摆上台面，使核龄**不依赖执行者记性**（护栏靠纪律，显示不靠任何人）。
     附带修掉一个隐性坑：HTML 原本只渲染 `f10_flag` 五个字、**从不渲染预告日期/内容**，读报告的人无从知道是什么点亮的、多老——年龄只躺在 JSON 里。
   → 对称参照：同一行的 `bad_nt`（减持/质押/解禁/立案关键词）扫的是 `_em_announcements(code, as_of_d)` 的**近期**公告，
     本就有日期边界——**代码原本自相矛盾：公告侧有年龄边界，预告侧没有**。
2. **搜索结果的旧闻污染**：同一次网页检索会把多年前旧文与当期新闻**混排返回、摘要常不带年份**，看着全像当期利空。
   宁德三条重磅红旗全是旧闻——"9.52亿股/近2800亿解禁"=**2021-06-11**（五年前）、"LG夺特斯拉43亿订单致宁王跌6%"=
   **2025-07-30**、"国会议员指强迫劳动/要求列实体清单"=**2024-06**。任一条误当当期即造成**错误否决**。
   → 护栏：每条红旗核到"年"再采信，核不出年份的不采信。
   → **方向性洞察**：前视纪律原只防"未来信息泄入"（致误给✓），旧闻污染是其**对称的另一半**（致误判✗）。
   后者更隐蔽——**空手不留痕迹，没人会去复盘一只没买的票**，影子日志也记不到它。

### 暴雷前 10—150 日 K 线轨迹研究（2026-08-02，只读面板重算；未改生产 workflow）

用户提出“暴雷前60个交易日的K线有什么共同特征、与未暴雷股票有什么区别”，因此在已锁 hash 的
`bottom_ml` 面板上追加 10/20/30/60/75/100/120/150 根 K 线事件研究。固定当前双路径、ATR≤4、
N=5冷却和 T+1 开盘后20日先+5%/先-8%标签；只保留 T 后仍有至少21根K线的成熟事件，避免样本尾部
只剩快速触发的输赢。成熟原始过线4473笔，冷却后1458笔（雷395/胜963/超时100），覆盖422只股票、
2024-01-15至2026-06-16；同股20市场交易日事件去重后1115笔。

- **共同轨迹**：全体过线票T前60日收盘收益中位-16.3%、窗口最大收盘回撤-26.8%、T收盘距窗口最高价
  -25.7%、距最低价仅反弹+5.6%、窗口位置12.9%；窗口后20%/前20%成交量比0.51。即“60日深跌、
  20—30日继续走弱、T附近只有微修复、量能收缩”，不是完整V型反转。
- **雷/胜几乎重合**：60日收益-16.36% vs -16.43%、最大回撤-27.30% vs -27.14%、距高点
  -25.90% vs -26.16%、位置13.14% vs 12.72%。10—60日的收益、回撤、位置、波动、连跌、阴线、
  缺口、下影与成交量均无稳定区分。
- **长窗是假分离**：全样本100—150日看似雷票跌得更久，但2024/2025/2026分段方向反复，同一信号日
  stop-win对照甚至反向；这是年份/regime构成，不是可部署的个股过滤器。
- **四重稳健门为0**：没有任何特征同时通过BH q、|AUC-0.5|≥0.06、三年同向、20日事件去重同向和
  同日对照。多窗口个股K线季度前推 Logistic 的5个季度宏平均AUC=0.503（范围0.412—0.658）。
