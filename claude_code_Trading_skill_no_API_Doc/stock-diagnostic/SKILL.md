# 单只A股持仓深度诊断（0 API · Claude Code 原生 · 5-Agent 辩论裁定）

## 这个 skill 怎么运作

**我（Claude Code）就是大脑，不调用任何外部 LLM API。** 我依次扮演 **5 个分析师 agent**，
用本机 Python 引擎（免费东财/腾讯/新浪行情 + 主力资金流 + IC 校准因子）+ 自带 WebSearch
（中文 + 英文、海内外）完成对**一只股票**的全维度研究与辩论，最后由第 5 个 agent 综合裁定，
**结合你的持仓成本**给出最可靠的后续操作建议。

定位：你**已持有或想买入**某只A股 → 给我 **代码 + 成本价** → 我从 技术/基本面/消息/资金/风险
五个维度彻底诊断 + 结合**整个A股**（同行、行业、板块、大盘）→ 给**综合裁定 + 操作矩阵**。

## 参数解析（先解析，再复述确认）

用户写法（中文冒号/等号/空格都认）：
```
/stock-diagnostic 股票代码=600519 成本价=1500
/stock-diagnostic 600519 1500
/stock-diagnostic 代码：300750 成本=180 持有天数=10
诊断一下 600036，我成本 40.5
```
| 用户写法（任一） | 含义 | 传给引擎 | 默认 |
|---|---|---|---|
| 股票代码 / 代码 / code / 第一个6位数 | 标的 | `--code` | **必填** |
| 成本价 / 成本 / cost / 第二个数 | 你的持仓成本 | `--cost` | 可空(则做通用诊断) |
| 持有天数 / 视野 / horizon / N | 评估视野(交易日) | `--hold-days N` | 20 |

解析不到成本价就提示"未给成本→做通用诊断，给了更准"。解析后**复述口径**（代码/名称/成本/视野）。

### 步骤 1 — Agent ①「技术·量价分析师」：跑引擎拿量化底座
```powershell
$env:PATH = [System.Environment]::GetEnvironmentVariable("PATH","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("PATH","User")
python "C:\Trading_analysis\Vibe-Trading-VT\claude_code_Trading_skill_no_API_Doc\stock-diagnostic\stock_diagnostic.py" --code 600519 --cost 1500 --hold-days 20 --out "C:\Trading_analysis\data\diag_latest.json"
```
引擎一次产出（读 stdout 表格 + `diag_latest.json`）：
- **量化分/风险分/持仓健康度/多空stance**（IC 校准因子权重，**≤24h 自动重跑**，首次或超24h会先花~1分钟校准）
- **技术面**：MA5/10/20/60 多空、MACD、RSI14、BOLL%b、5/20/60日动量、60/120/250日位置、距年高、ATR%、信号
- **支撑/压力**、**关键价位地图**（止损/加仓区/止盈区）、**情景分析**（看多/基准/看空目标）
- **资金面**：个股主力资金近5/10日净流入额与占比（超大单+大单）
- **同行对比**：所属行业板块成分股 20 日相对强弱排名（匹配不到板块时此项交给 Agent④ WebSearch）
- **大盘环境**：上证/深证/创业板/沪深300 涨跌 + 是否站上MA20 + regime
- **成本相关**：盈亏%、解套需涨%、成本位置、等量补仓后新成本/解套涨幅
> Agent① 读完给：技术多空结论 + 一句话量价逻辑（趋势/位置/量价是否健康）。

### 步骤 2 — Agent ②「基本面·财务分析师」：WebSearch 估值与业绩
基于引擎给的 PE/PB/市值/行业，**WebSearch 补全基本面**：
- **估值**：当前 PE/PB 处于自身历史/行业的什么分位（便宜还是贵）；PEG。
- **业绩**：最近一期营收/净利润同比、增速趋势、毛利率/ROE、是否有业绩预增/暴雷、机构盈利预测。
- **质地**：现金流/负债/商誉、是否高股息、行业地位（龙头/跟随）。
- 搜索词模板：`"{股票名} 业绩 最新 净利润"`、`"{股票名} 估值 PE 历史分位"`、`"{股票名} 机构 评级 目标价"`、`"{行业} 景气度 2026"`。
> Agent② 给：基本面多空分(0-100) + 估值贵/合理/便宜 + 业绩趋势一句话 + 是否支撑当前价。

### 步骤 3 — Agent ③「消息·催化剂分析师（中英文 · 海内外）」：WebSearch 全网资讯
**必须中英文双语、覆盖海内外**，逐类搜：
- **公司公告/事件**：业绩预告、重组并购、回购/增持、减持、解禁、中标/大订单、诉讼、问询函。
- **券商研报/评级**：最新评级、目标价、研报观点（看多/看空逻辑）。
- **政策/行业催化**：相关产业政策、补贴、监管、行业会议。
- **海外/英文**：英文媒体与海外同业（如：半导体看美股/全球周期、出口看海外需求、有 ADR/港股的看海外定价、行业全球龙头动向）。搜索词如 `"{英文公司名或行业} stock news analysis"`、`"{sector} outlook 2026 demand"`、`"{ticker} earnings guidance"`。
- **情绪/热度**：股吧/雪球/北向关注度（仅作情绪参考，注明不可全信）。
- **判断"利好是否已 price-in"**（消息出来前是否已大涨）。
> 纪律：具体数字/价格必须来自 WebSearch 或引擎，**严禁用训练记忆里的旧数**。
> Agent③ 给：消息面多空分(0-100) + 近期最强催化剂/最大利空各一句 + price-in 判断。

### 步骤 4 — Agent ④「资金·板块·大盘联动分析师」
综合引擎的客观数据 + WebSearch 的板块视角：
- **个股资金**：引擎主力5/10日净流入趋势（持续流入=有资金照顾；持续流出=注意）。
- **同行/板块**：引擎同行 20 日强弱排名（强于/弱于同行）；WebSearch 该**行业/板块是否在轮动风口**、龙头是谁、本股在板块中的地位。
- **大盘**：引擎指数 regime（risk-on/off）；WebSearch 北向资金/两市情绪/近期市场风格（大小盘、价值成长）。
- **拥挤度**：是否扎堆热门题材、换手是否过热。
> Agent④ 给：资金·板块多空分(0-100) + 资金流向 + 板块景气 + 相对强弱一句话。

### 步骤 5 — Agent ⑤「风险挑战者 · 首席裁决官」：看空挑刺 + 综合裁定 + 操作
**先当空头**，逐条挑战①~④的看多逻辑：
- 估值过高/业绩兑现见顶/赛道拥挤/技术破位/高位放量滞涨/解禁减持/商誉雷/政策风险/流动性/系统性回调风险。
- 用引擎客观风险分(0–100)做基准，叠加上述基本面/事件风险，定**风险等级**。
**再综合裁定**（5 维加权）：
```
综合多空分(0~100) = 技术×0.28 + 基本面×0.22 + 消息×0.22 + 资金·板块×0.28
最终分 = 综合多空分 − 风险分×0.15 + 大盘regime调整(±5)
```
- **置信度**：≥75 且 ≥4维同向→高；60–74 或 3维同向→中高；45–59 分歧→中；<45→低/规避。
- **结合你的成本**给操作（见下方"操作矩阵"），并给**具体价位**：加仓/补仓区、止盈区、止损位、清仓触发。
- **R:R 校验**：上行空间/下行空间≥1.5 才值得继续持有/加仓，否则倾向减。

### 步骤 6 — 输出最终诊断（必须给这几块）

**① 5 维综合裁定表**
```markdown
## 个股诊断裁定 — {名称}({代码})  T={日期}  视野=T+{N}  成本={cost} 盈亏={pnl}%

| 维度 | 评分(0-100) | 多空 | 关键依据(一句话) |
|---|---|---|---|
| ① 技术·量价 | xx | 多/空/中 | 趋势+位置+量价 |
| ② 基本面·财务 | xx | 多/空/中 | 估值分位+业绩趋势 |
| ③ 消息·催化剂 | xx | 多/空/中 | 最强催化剂 / price-in |
| ④ 资金·板块·大盘 | xx | 多/空/中 | 主力流向+板块景气+相对强弱 |
| ⑤ 风险 | 风险xx(等级) | — | 最大风险点 |
| **综合裁定** | **最终分** | **结论** | **置信度 高/中高/中/低** |
```

**② 操作建议（结合成本，给具体价位）**
```markdown
| 操作 | 触发/区间 | 仓位建议 | 理由 |
|---|---|---|---|
| 加仓/补仓 | 回踩 {加仓区} 且 {趋势条件} | +x% | … |
| 持有 | 站稳 {支撑}~{压力} 之间 | 维持 | … |
| 止盈/减仓 | 冲到 {止盈区} 或 {过热信号} | 减x% | … |
| 止损/清仓 | 跌破 {止损位} 或 {破位信号} | 清 | … |
```

**③ 操作方案（分情景 · 含 T+N 到期处理）** —— 引擎已自动生成结构化方案，覆盖：现在/回踩加仓区/反弹压力区/冲看多目标/跌破止损/**持有到期 T+N** 六类情景，每行给 动作+仓位+说明（末行直接回答"到期该不该清"）。Agent⑤ 据基本面/消息**逐行细化**（可改触发价/仓位比例/增删行），不要只给一句话。

**④ 关键价位地图** + **⑤ 情景分析(看多/基准/看空)** + **⑥ 五方分歧与裁决** + **⑦ 风险提示**

> **操作矩阵（裁决核心，按"成本状态 × 趋势"）**：
> - **浮盈 + 健康上涨**：持有，跟踪止盈（移动止损上移）；回踩支撑可加。
> - **浮盈 + 过热(60日位>92/RSI>80/高位放量)**：减仓锁利一部分，剩余设紧止盈。
> - **浮亏(轻) + 趋势未破**：持有，跌破关键支撑/止损位再走；回踩可小幅摊薄。
> - **深套(>15%) + 下跌趋势 + 资金流出**：**不补仓**（不接下跌的刀），反弹到压力/解套位减仓或止损。
> - **深套 + 趋势已转好(站上MA20+主力转净流入+MACD金叉)**：可**分批**补仓摊薄（仅此情形）。
> - **基本面恶化/业绩暴雷/退市风险**：无视技术反弹，优先清仓。
> 单一标的仓位上限建议 ≤ 总仓 15–20%；明确止损纪律；A股 T+1（当日买入次日才能卖）。

## 硬性纪律
1. **0 API**：除自带 WebSearch 外不调用任何付费 LLM/数据 API。
2. **真实数据**：行情/资金流来自引擎实时拉取，资讯来自 WebSearch（中英文海内外），严禁编造/用旧记忆数。
3. **qlib 权重最多 1 天重跑**：引擎默认 `--weights auto`，weights.json 超 24h 或视野不匹配会自动重跑 IC 回测，保证最新最 predictive。
4. **结合整个A股**：必须带入同行/行业/板块/大盘环境，不就个股论个股。
5. **结合成本**：所有操作建议要落到用户成本上（盈亏/解套/加仓摊薄/止盈止损），给**具体价位**。
6. **风险优先**：风险等级"高"或基本面恶化时，即使技术看多也要降置信度或转防守。
7. 全程中文（英文资讯翻译要点呈现）；结尾声明：研究分析**非投资建议**，A股 T+1。

## 还有什么 helpful（已内置，可主动用）
