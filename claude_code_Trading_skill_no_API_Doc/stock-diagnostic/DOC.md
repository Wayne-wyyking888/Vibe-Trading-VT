# stock-diagnostic — 完整文档

单只A股「持仓深度诊断」skill。Claude Code 原生、**0 API**、真实免费行情，**5-Agent 辩论裁定**。
给一只票的**代码 + 你的持仓成本**，从 技术/基本面/消息/资金/风险 五维彻底诊断 + 结合**整个A股**
（同行/行业/板块/大盘）→ 给**综合裁定 + 结合成本的操作建议**（加仓/持有/减仓/止损，带具体价位）。

## 🚀 怎么调用（样板 wording，复制改数字）

```
/stock-diagnostic 股票代码=600519 成本价=1500
/stock-diagnostic 600519 1500
/stock-diagnostic 代码：300750 成本=180 持有天数=10
诊断一下 600036，我成本 40.5，最多拿一个月
我 600036 套了，成本40，现在怎么操作？
```
- **必填**：股票代码。**强烈建议**：成本价（给了才能算盈亏/解套/补仓/止盈止损；不给则做通用诊断）。
- 可选：持有天数/视野 N（默认 20 个交易日，驱动情景目标与 IC 回测窗口）。

调用后我（Claude Code）会：解析参数 → 跑引擎拿量化底座（技术/资金/同行/大盘/成本）→ 扮演 5 个 agent
（②基本面 ③消息中英文 ④资金板块 由 WebSearch 补全，⑤风险裁决综合）→ 给**多维评分表 + 操作矩阵 +
关键价位地图 + HTML 报告**。**0 API、0 额外花费。**

## 5 个 Agent（我依次扮演，最后综合裁定）

| Agent | 角色 | 数据来源 | 产出 |
|---|---|---|---|
| ① | 技术·量价分析师 | Python 引擎（东财/腾讯行情 + IC 校准因子） | 趋势/动量/MACD/RSI/BOLL/位置/支撑压力/ATR + 多空 stance |
| ② | 基本面·财务分析师 | WebSearch + 引擎 PE/PB/市值 | 估值分位/业绩趋势/成长/质地 → 基本面多空分 |
| ③ | 消息·催化剂分析师（**中英文·海内外**） | WebSearch（中文+英文） | 公告/研报/政策/海外同业/情绪 + price-in 判断 → 消息多空分 |
| ④ | 资金·板块·大盘联动分析师 | 引擎主力资金流 + 同行 + 指数 + WebSearch | 资金流向/板块景气/相对强弱/大盘 regime → 资金多空分 |
| ⑤ | 风险挑战者·首席裁决官 | 综合 ①~④ + 引擎风险分 | 看空挑刺 + 5维加权裁定 + 结合成本的操作建议 |

**综合裁定打分**：
```
综合多空分 = 技术×0.28 + 基本面×0.22 + 消息×0.22 + 资金·板块×0.28
最终分 = 综合多空分 − 风险分×0.15 + 大盘regime调整(±5)
置信度：≥75且≥4维同向→高 / 60–74或3维同向→中高 / 45–59分歧→中 / <45→低·规避
```

## 引擎命令行
```
python stock_diagnostic.py --code 600519 [选项]
  --code 600519       股票代码（必填）
  --cost 1500         持仓成本价（可选，给了算盈亏/解套/补仓/止盈止损）
  --hold-days N       评估视野(交易日)。默认20。驱动情景目标 + IC回测窗口
  --weights auto      ≤24h 自动校准IC权重(默认)；none=用持有天数自适应默认权重(更快)
  --out 路径.json     结果写JSON（默认 C:\Trading_analysis\data\diag_latest.json）
  --refresh           强制重拉行情（绕过缓存）
  --no-report         不生成HTML报告
```
> Windows：先刷新 PATH，且行情请求要 `dangerouslyDisableSandbox: true`（沙箱拦外网）。

### 引擎产出（Agent① 量化底座，写入 JSON + stdout + 预览HTML）
1. **个股快照**：现价/今涨/PE/PB/总市值·流通市值/换手/量比/行业/板块（东财 stock/get → 腾讯兜底）。
2. **技术面**：MA5/10/20/60 多空、MACD、**RSI14**、**BOLL%b**、5/20/60日动量、**60/120/250日位置**、
   距年高、ATR%、尾盘/连板信号；**支撑/压力**（MA + 近20/60日高低 + 年内高低）。
3. **量化分**（IC 校准因子，0–100）+ **客观风险分**（0–100 + 等级）+ **持仓健康度** + **多空 stance**。
4. **主力资金流**：近5/10日主力净流入额与占比（超大单+大单）。主源东财历史日线，限流时回退实时单日。
5. **同行对比**：所属行业板块成分股 20 日相对强弱排名（匹配不到板块→标记交给 Agent④ WebSearch）。
6. **大盘环境**：上证/深证/创业板/沪深300 涨跌 + 是否站上MA20 + regime（偏多/中性/偏空）。
7. **成本相关**：盈亏%、状态（浮盈/浮亏/深套）、**解套需涨%**、成本相对现价/MA20 位置、
   **等量补仓后新成本与新解套涨幅**。
8. **情景分析**（T+N 看多/基准/看空目标 + 相对现价幅度）+ **关键价位地图**（止损/加仓区/MA20/止盈区）。
9. **引擎基线动作** + **结构化操作方案**：分情景表（现在/回踩加仓区/反弹压力区/冲看多目标/跌破止损/**持有到期 T+N**），
   每行给 动作+仓位+说明——**末行直接回答"到 T+N 该不该清仓"**（按 浮盈/轻套/深套 给不同到期处理）。作为 Agent⑤ 裁决底座，可被细化。

## qlib 风格因子权重（≤24h 自动重跑，保证最新最 predictive）
- 默认 `--weights auto`：引擎检查 `weights.json`，若**超 24 小时**或**视野(fwd_days)不匹配**，
  自动重跑一次横截面 **IC 回测**（全市场 ~50 样本股，Spearman 秩相关，因子=本引擎 + qlib Alpha158/gtja191
  风格公式化因子），按 |IC| 归桶刷新权重；满足则**复用**（不每次跑）。
- 这保证给量化分的因子配比始终基于近一日的市场有效性（不是手拍、不是过时权重）。
- 想跳过校准更快：加 `--weights none`（用持有天数自适应默认权重）。

## HTML 报告（每次run自动生成）
- **文件名**：`diag_{代码}_cn_YYYY-MM-DD_HH-MM-SS.html`，时间戳=**中国当地时间(UTC+8)**。
- **结构**：顶部信息条 → **裁决横幅**（操作/置信度/健康度/量化分/风险） → 关键指标条（现价/盈亏/PE·PB/市值/stance）
  → **5-Agent 综合裁定表** → **关键价位地图** → 四卡片（技术/成本/资金流/大盘） → 同行对比表 → 引擎基线动作 → 五方辩论与裁决全文。
- **5-Agent 综合裁定表**：①②③④ 看多强度(0-100, 越高越偏多)、⑤ 风险(越低越好)，每行标注方向；
  末行 **综合裁定** = `技术×0.28+基本面×0.22+消息×0.22+资金×0.28−风险×0.15`（`final_score` 不填则自动合成）。
- **横幅**指标都带方向标注：持仓健康度↑、量化买入分↑（0-100，弱势持仓可能接近0属正常）、技术风险↓
  （注意：横幅"技术风险"是引擎客观技术风险；表格⑤是叠加基本面/事件后的综合风险，两者可不同）。
- **关键价位地图**：每个 cell 内含一句说明（止损=破位离场、加仓区=回踩低吸、MA20=中期多空线…）。
- **报告留存规则**（文件名时间戳 = **本次诊断生成时间**，取自结果JSON的 `cn_time`，不是渲染时刻）：
  - **同一次诊断**无论重渲染几次（预览→完整→补全后再出完整）都映射到**同一文件名→覆盖自身**，**不产生中间半成品文件**。
  - **不同诊断**（重新跑引擎，诊断时间不同）→ 各存一份完整版，**永久保留**，可对比同一只票历次诊断。
  - **半成品预览**（引擎直出的 `diag_{代码}_preview_cn_{时间}.html`）不累积，出完整版时自动清掉。
  - reports/ 是 gitignore 的临时产物。`render_html(r, is_final=False)` 出预览、`is_final=True`(默认) 出完整版。
- **预览 vs 完整版**：引擎自动出的是量化预览（②③维度显示"待回填"）；做完 Agent②~⑤ 后回填 JSON
  （`final_action`/`final_confidence`/`final_score`/`agent_scores`/`agents_md`/`final_md`）再
  `python make_diag_report.py --in diag_latest.json` 出**完整版**（会自动替换掉预览）。

## 操作矩阵（裁决核心，按"成本状态 × 趋势"）
| 成本状态 | 趋势/信号 | 建议 |
|---|---|---|
| 浮盈 | 健康上涨 | 持有，移动止损上移；回踩支撑可加 |
| 浮盈 | 过热(60日位>92/RSI>80/高位放量) | 减仓锁利一部分，余仓紧止盈 |
| 浮亏(轻) | 趋势未破 | 持有；跌破关键支撑/止损位再走；回踩可小幅摊薄 |
| 深套(>15%) | 下跌趋势 + 资金流出 | **不补仓**（不接下跌的刀），反弹到压力/解套位减仓或止损 |
| 深套 | 趋势已转好(站上MA20+主力转净流入+MACD金叉) | 可**分批**补仓摊薄（仅此情形） |
| 任意 | 基本面恶化/业绩暴雷/退市风险 | 无视技术反弹，优先清仓 |
> 单标的仓位 ≤ 总仓 15–20%；明确止损纪律；A股 T+1（当日买入次日才能卖）。

## 次日盘前复核（recheck_diag.py）
买入/加仓当天早上 9:15–9:30 或盘中跑：读 `diag_latest.json`，腾讯拉实时价，对照成本/止损/价位地图给即时建议
（进加仓区 / 进止盈区 / 跌破止损 / 区间内持有）。
```
python recheck_diag.py --in C:\Trading_analysis\data\diag_latest.json
```

## 数据源与容错
- 个股快照：东财 stock/get → 腾讯兜底；K线：东财 → 腾讯（当天缓存 TTL 60h）。
- 主力资金流：东财历史日线(push2his, 含占比) → 东财实时单日(push2, 仅当日) 跨主机回退；都不行则标"暂不可用"交 WebSearch。
- 同行：东财板块成分（行业名清洗罗马数字后匹配；匹配不到不回退全市场，交 Agent④ WebSearch）。
- 大盘：东财指数 stock/get + K线。交易日历：akshare 权威源（含节假日，缓存30天）。
- 东财限流：多镜像轮换 + 指数退避 + 熔断 + 当天缓存兜底。连续测试触发限流就停手等 1–2 分钟。

## 已知限制
- f127 行业名是申万口径（如"银行Ⅱ""电池"），与东财板块名不总一一对应；匹配不到时同行对比交给 WebSearch（不影响主诊断）。
- 主力资金流历史源（push2his）偶发限流，会回退到"仅最新日"，报告会标注。
- 引擎只做量价/技术/资金/位置/成本的客观计算；基本面与消息面由 Agent②③（WebSearch）补足。
- 结果为量化 + 研究分析，**非投资建议**；A股 T+1，当日买入次日才能卖。成本相关测算仅供参考。
